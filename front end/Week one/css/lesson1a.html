CSS

This is also known as cascading style sheet

Mainly used to style the appearance of a web site


Why introduced

Was introduced in 1996 by the world web consortium to help in more advanced styling and separation of content and presentation

  1. Application of same style to multiple elements
  2. Control presentation of multiple pages using one sheet
  3. Presentation of same page diffrently in diffrent devices
  4. Styling dynamic states of elements
  5. Changing the position of an element without changing the markup
  6. Alter display and change alter transformation of elements in 2d or 3d Based on preference

Advantages of using CSS

  • Sepparation of style and layout
  • Flexibility since it setts styles outside elements
  • Easy maintanance time
  • Page loads faster
  • Supperior styles more than what html can handle
  • Many device compatibility
Ways to Implement CSS
  • Inline
  • Embeded/internal
  • External
